# Markdown.me

Нативный Markdown-редактор для macOS (Swift, SwiftUI + AppKit), распространяется вне App Store.

- Требования: `docs/spec.md`
- План, архитектурные решения, индекс задач: `docs/PLAN.md`
- Подпись кода и TCC (обязательно к прочтению перед правкой скриптов сборки): `docs/macos-signing-tcc.md`
- Задачи: Notion, база «Markdown.me — Task list» (ссылка в `docs/PLAN.md`)

## Правила

- Одна задача MD-N — одна ветка и PR. Делать только то, что в задаче; архитектурные
  изменения — через правку таблицы решений в `docs/PLAN.md`.
- `MarkdownCore` не импортирует AppKit и SwiftUI.
- Никаких визуальных значений в коде вьюх: только `DesignTokens.swift` (после MD-2).
- Все строки UI — через ключи локализации, с первого дня.
- Приложение собирается и запускается только на Mac. В облачной (Linux) сессии не
  обещать, что UI-код работает, если его не собирали.

## Команды

Появятся в MD-1 (сборка, тесты, запуск) и MD-2 (lint токенов).
